Sync V0 from Google Sheet
V0 is the canonical test case library. Syncing replaces V0 cases with the live data from your Google Sheet. Existing V1, V2, … runs are never affected.
In your Google Sheet → Extensions → Apps Script. Paste the function below, then Deploy → New deployment → Web App → Anyone.
function doGet() { const ss = SpreadsheetApp.getActiveSpreadsheet(); const allData = {}; ss.getSheets().forEach(sheet => { const name = sheet.getName(); const rows = sheet.getDataRange().getValues(); if (rows.length < 2) return; const headers = rows[0]; allData[name] = rows.slice(1).map(r => { const obj = {}; headers.forEach((h, i) => { if(h) obj[h] = r[i] ?? ''; }); return obj; }).filter(r => r['TC ID'] || r['id']); }); return ContentService .createTextOutput(JSON.stringify(allData)) .setMimeType(ContentService.MimeType.JSON); }
The URL ends in /exec. Make sure access is set to Anyone.
